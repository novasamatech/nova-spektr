```sh
# Setup dev environment
pnpm install
```

## Environment variables

Copy `.env.example` to `.env` (git-ignored) and fill in the values before building:

- `WALLET_CONNECT_PROJECT_ID` — WalletConnect Cloud project id, baked into the renderer at build time. Create one at
  [cloud.reown.com](https://cloud.reown.com). In development it may be empty: WalletConnect / Nova Wallet pairing is
  hidden and the sign client is never initialised. Staging and production builds fail with an error without it.

The id is embedded in the shipped bundle, so it is a repository **variable** in CI, not a secret
(Settings → Secrets and variables → Actions → Variables → `WALLET_CONNECT_PROJECT_ID`). The `docker-compose.yml`
system-test setup starts the development server without the id, so WalletConnect stays hidden there.

Manual steps after moving the id out of source:

1. Rotate the previously committed project id at [cloud.reown.com](https://cloud.reown.com) — it is still visible in git
   history.
2. Set the new id as the `WALLET_CONNECT_PROJECT_ID` repository variable in GitHub Actions.

## Development

```sh
# Start Electron app in dev mode. You can also access app with browser
pnpm start
```

```sh
# Start renderer without Electron (not recommended)
pnpm start:renderer
```

### Testing

```sh
# Run unit tests for renderer
pnpm test
```

```sh
# Run unit tests in watch mode
pnpm test:watch
```

```sh
# Watch unit tests with vite ui plugin
pnpm test:ui
```

```sh
# Collect coverage from unit tests
pnpm test:coverage
```

```sh
# Run integration tests (tests/integrations/)
pnpm test:integration
```

```sh
# Run e2e tests
pnpm test:system
```

### Linting

```sh
# Run linter
pnpm lint
```

```sh
# Check formatting
pnpm fmt:check
```

```sh
# Auto-fix formatting
pnpm fmt:fix
```

```sh
# Run linter and formatter with autofix
pnpm lint:fix
```

```sh
# Run typescript typechecker
pnpm types
```

```sh
# Run typescript typechecker via tsgo (~6x faster, preferred)
pnpm types:go
```

## Building

```sh
# Start Electron and prebuild app in staging mode. You can also access app with browser
pnpm preview
```

```sh
# Build app in development mode
pnpm build:dev
```

```sh
# Build app in staging mode
pnpm build:staging
```

```sh
# Build app in production mode
pnpm build
```

```sh
# Full staging build sequence (clean, build, postbuild, dist)
pnpm staging:sequence
```

```sh
# Full production build sequence (clean, build, postbuild, dist)
pnpm prod:sequence
```
